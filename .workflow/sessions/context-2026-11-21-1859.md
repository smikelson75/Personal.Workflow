## Language
- New/changed terms this session; full definitions in `language.md`.
- `Language Add-on` - updated code path to `language-addons/`.
- `Behavior Spec` - black-box behavioral contract derived from the Session Chain.
- `Plan` - routing record and current-state status for a product.
- `Phase` - one delivery stage delivering end-to-end value.
- `Slice` - one thin vertical unit of observable behavior.
- `Card` - one closed-world work brief in a Phase file.
- `Scenario` - one concrete acceptance case owned by a `build` Card.
- `Tier` - who implements a Card (`delegate` or `main`).
- `Gate` - automated phase-end verification run without the Developer.
- `Phase Review` - Checkpoint approving Cards, acceptance cases, Tiers, `Review` flags, and ADR candidates.
- `Setup-Card Approval` - Checkpoint in Plan mode approving setup Cards before acceptance authoring.
- `Oracle` - union of paths holding acceptance suites, fixtures, and harness configuration.
- `Traceability` - Gate verification that every owned Scenario has a passing tagged case.
- `ADR` - point-in-time record of an approved, hard-to-reverse build decision.
